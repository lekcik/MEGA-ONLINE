# MEGA — 1v1 Asymmetric Multiplayer (Human vs Monster)

Кросплатформний **Windows <-> Linux** мультиплеєр без сторонніх VPN і **без жодних зовнішніх бібліотек чи завантажень під час збірки**:
- **100% автономний рушій**: гра використовує вбудований платформений шар (`Win32 + WGL + RawInput + waveOut` на Windows, `X11 + GLX + ALSA` через `dlopen` на Linux) та власний завантажувач `OpenGL 3.3 Core` (`GlApi`). Жодних `SDL3`, `libepoxy`, `FetchContent`, `vcpkg` чи `pkg-config`.
- **Мультиплеєр без Radmin VPN**: вбудований **UPnP IGD** + **STUN-код кімнати (`XXXX-XXXX-XXXX`)** + **UDP Hole Punching**.
- **Без ШІ-ботів в онлайні**: виключно **1 Людина** проти **1 Монстра**.
- **Без вогнепальної зброї**: стрільба повністю вирізана — виживання через стелс, шафки, витривалість, ближній бій та крафт.
- **Оригінальна графіка збережена**: світові шейдери, текстури, освітлення та HUD людини залишились 1:1 як в оригінальному репозиторії (нічне бачення монстра реалізовано лише у фінальному пост-процесі `Framebuffer`).

## 1. Запуск і збірка

### Windows (твій ноутбук)
Просто **двічі клікни файл `PLAY_WINDOWS.bat`** у папці `MEGA`!
- Якщо `build\mega.exe` ще не зібраний, скрипт сам знайде встановлений компілятор `g++` (або сам поставить WinLibs), збере `build\mega.exe` за ~5 секунд **без інтернету й без CMake FetchContent** і одразу запустить гру.
- Якщо хочеш перезібрати вручну, просто двічі клікни `build_windows.bat`.

### Linux (ноутбук друга — Ubuntu / Debian / Arch / Fedora)
Потрібен тільки `g++` (навіть `-dev` пакети SDL/X11/GL не обов'язкові, бо бібліотеки підвантажуються динамічно):
```bash
chmod +x build_linux.sh
./build_linux.sh
./build/mega
```

## 2. Як підключитися без Radmin VPN (Windows <-> Linux)

Гра автоматично визначає зовнішню адресу через **STUN** і намагається відкрити UDP-порт через **UPnP** на роутері.

### Спосіб А — Звичайне підключення по коду кімнати (через вбудоване лобі)
1. **Хост (наприклад, ти на Windows)**:
   - Запусти `PLAY_WINDOWS.bat`, натисни **`2` (HOST 1V1 MATCH)** (або стрілки + `ENTER`).
   - Обери роль (`Human` або `Monster`) стрілками `<-` / `->` або `ENTER`.
   - На екрані з'явиться **ROOM CODE** формату `XXXX-XXXX-XXXX`.
   - Перейди на пункт Start і натисни **`ENTER`**, та надішли другу **ROOM CODE**.
2. **Гість (друг на Linux)**:
   - Запусти `./build/mega`, обери **JOIN 1V1 MATCH**.
   - Введи **ROOM CODE** хоста (або його LAN IP, якщо ви в одній Wi-Fi мережі) і натисни **`ENTER`**.
3. **Якщо у обох строгий NAT (UPnP недоступний)**:
   - На екрані **JOIN** у гостя показується його власний **GUEST CODE** (`XXXX-XXXX-XXXX`).
   - Гість передає свій **GUEST CODE** хосту, а хост вводить його в поле **GUEST CODE (IF NO UPNP)** на екрані **HOST** — обидва комп'ютери одночасно пробивають NAT (`UDP Hole Punch`).

> **Підказка для Windows Firewall**: При першому запуску `mega.exe` Windows може запитати дозвіл мережі — обов'язково натисни **Allow / Дозволити**.

## 3. Керування (Controls)

### Людина (Human / Survivor)
- **Рух / Спринт / Стрибок**: `W A S D` / `Shift` / `Space`
- **Ліхтарик**: `F`
- **Взаємодія / Двері / Шафки / Предмети / Взлом замків**: тримай `E` (+ рух мишею для дверей/шафок)
- **3D Рюкзак (в руках / покласти на підлогу)**: `Tab` / `B`
- **Обертання предмета / Рюкзака**: `T Y R` / тримай `RMB` + миша
- **Ближній бій** (`Broom`, `Mop`, `Stick`, `Knife`, скрафчений `Spear`): `LMB`
- **Швидке використання**: `1` Батарейка, `2` Їжа, `3` Вода

### Монстр (Monster / Stalker)
- **Рух / Спринт**: `W A S D` / `Shift`
- **Ривок (Lunge / Dash)**: `RMB` або `Space` (перезарядка `3.2с`)
- **Удар кігтями / Вибити незамкнену шафку**: `LMB`
- **Перевірити / Відкрити шафки та двері**: `E`
- **Нічне бачення (Night Vision)**: `N`
