# MEGA — 1v1 Asymmetric Multiplayer (Human vs Monster)

Кросплатформний **Windows <-> Linux** мультиплеєр без сторонніх VPN і без ручного встановлення бібліотек:
- **Нуль ручних залежностей**: `CMake` автоматично завантажує та статично лінкує `SDL3` (`FetchContent`), а завантаження функцій `OpenGL 3.3 Core` вбудовано прямо в рушій (`GlApi`). Жодних `libepoxy`, `pkg-config` чи `vcpkg`.
- **Мультиплеєр без Radmin VPN**: вбудований **UPnP IGD** + **STUN-код кімнати (`XXXX-XXXX-XXXX`)** + **UDP Hole Punching**.
- **Без ШІ-ботів в онлайні**: виключно **1 Людина** проти **1 Монстра**.
- **Без вогнепальної зброї**: стрільба повністю вирізана — виживання через стелс, шафки, витривалість, ближній бій та крафт.
- **Оригінальна графіка збережена**: світові шейдери, текстури, освітлення та HUD людини залишились 1:1 як в оригінальному репозиторії (нічне бачення монстра реалізовано лише у фінальному пост-процесі `Framebuffer`).

## 1. Збірка (Zero Manual Dependencies)

Потрібні лише **CMake (>= 3.20)** і **C++20 компілятор** (при першій збірці потрібен інтернет, щоб CMake один раз завантажив SDL3).

### Linux (ноутбук друга — Ubuntu / Debian / Arch / Fedora)
Встановити лише стандартний компілятор, `cmake` і системні OpenGL-заголовки:
- **Ubuntu / Debian**:
  ```bash
  sudo apt install cmake g++ libgl-dev
  ```
- **Arch Linux**:
  ```bash
  sudo pacman -S cmake gcc libglvnd
  ```
- **Fedora**:
  ```bash
  sudo dnf install cmake gcc-c++ mesa-libGL-devel
  ```
Збірка та запуск:
```bash
chmod +x build_linux.sh
./build_linux.sh
./build/mega
```

### Windows (твій ноутбук)
Достатньо мати **CMake** + **Visual Studio / Build Tools (C++)** або **MinGW-w64 (`g++`)**.
Просто запусти:
```bat
build_windows.bat
```
Готовий виконуваний файл (`build\Release\mega.exe` або `build\mega.exe`) **не потребує жодних `SDL3.dll` або `libepoxy.dll`** — SDL3 вшито статично.

## 2. Як підключитися без Radmin VPN (Windows <-> Linux)

Гра автоматично визначає зовнішню адресу через **STUN** і намагається відкрити UDP-порт через **UPnP** на роутері.

### Спосіб А — Звичайне підключення по коду кімнати (через вбудоване лобі)
1. **Хост (наприклад, ти на Windows)**:
   - Запусти `mega.exe`, натисни **`2` (HOST 1V1 MATCH)**.
   - Обери роль: **`H`** (грати за Людину) або **`M`** (грати за Монстра).
   - У меню з'явиться **ROOM CODE** формату `XXXX-XXXX-XXXX` (та статус `UPNP: PORT OPEN` або `UPNP: NO IGD / NAT PUNCH MODE`).
   - Натисни **`ENTER`**, щоб відкрити кімнату, і надішли другу **ROOM CODE** (наприклад, у Telegram/Discord).
2. **Гість (друг на Linux)**:
   - Запусти `./mega`, натисни **`3` (JOIN 1V1 MATCH)**.
   - Введи **ROOM CODE** хоста (або його LAN IP, якщо ви в одній Wi-Fi мережі) і натисни **`ENTER`**.
   - Якщо статус у хоста був `UPNP: PORT OPEN`, з'єднання встановиться миттєво!
3. **Якщо у обох строгий NAT (UPnP недоступний)**:
   - На екрані **JOIN** у гостя показується його власний **GUEST CODE** (`XXXX-XXXX-XXXX`).
   - Гість передає свій **GUEST CODE** хосту, а хост вводить його в поле **GUEST CODE (IF NO UPNP)** на екрані **HOST** (клацни по полю або натисни **`G`** / встав код) — обидва комп'ютери одночасно пробивають NAT (`UDP Hole Punch`).

> **Підказка для Windows Firewall**: При першому запуску Windows може запитати дозвіл мережі для `mega.exe` — обов'язково натисни **Allow / Дозволити**.

### Додаткові CLI-прапорці запуску
```bash
# Запустити хост за Людину на порту 7777
./mega --host --role human --port 7777

# Запустити хост + одночасно пробивати NAT до Guest Code клієнта
./mega --host --role human --punch ABCD-EFGH-2345

# Приєднатися за кодом кімнати (або IP)
./mega --join K7M2-P9QX-4R8T

# Соло-тренування
./mega --solo
```

- Натисни **`F1`** у будь-який момент, щоб повернутися в Лобі.
- Після завершення раунду Хост може натиснути **`R`**, щоб почати реванш з новим сідом мапи.

## 3. Керування (Controls)

### Людина (Human / Survivor)
- **Рух / Спринт / Стрибок**: `W A S D` / `Shift` / `Space`
- **Ліхтарик**: `F`
- **Взаємодія / Двері / Шафки / Предмети / Взлом замків**: тримай `E` (+ рух мишею для дверей/шафок)
- **3D Рюкзак (в руках / покласти на підлогу)**: `Tab` / `G`
- **Обертання предмета / Рюкзака**: `X Y Z` / тримай `RMB` + миша
- **Ближній бій** (`Broom`, `Mop`, `Stick`, `Knife`, скрафчений `Spear`): `LMB`
- **Використати / Поставити предмет у руках**: `U` / `RMB`, потім `LMB`
- **Швидке використання**: `1` Батарейка, `2` Їжа, `3` Вода

### Монстр (Monster / Stalker)
- **Рух / Спринт**: `W A S D` / `Shift` (витрачає і відновлює витривалість)
- **Ривок (Lunge / Dash)**: `RMB` або `Space` (ривок уперед, перезарядка `3.2с`)
- **Удар кігтями / Вибити незамкнену шафку**: `LMB` (блокується стінами і зачиненими дверима — удар по зачиненій шафці виламує її!)
- **Перевірити / Відкрити шафки та двері**: `E` (натиснути або тримати + миша)
- **Нічне бачення (Night Vision)**: `N` (увімкнути/вимкнути підсилення світла в фінальному пост-процесі)
